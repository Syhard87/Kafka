# Ce qu'on trouve dedans (chaînes lisibles extraites des fichiers) :
  _metadata         : SourceReaderState / SPLIT_DISTRIBUTE / commandes   -> offsets Kafka lus par chaque sous-tâche source
                      watermark                                          -> watermark de la source
                      writer_raw_states / alertes-exam-eos               -> état du writer Kafka (préfixe transactionnel)
                      streaming_committer_raw_states                     -> transactions à valider à la fin du checkpoint
  (checkpoint n°16) fichier n°1 : _timer_state/event_window-timers + 262 clients C0xxxxx -> fenêtres ouvertes (accumulateurs) et timers
  (checkpoint n°16) fichier n°2 : _timer_state/event_window-timers + 303 clients C0xxxxx    de chaque sous-tâche (clés réparties par hash)
  + les "serializer snapshots" (RowDataSerializer, LongSerializer...)   -> le schéma nécessaire pour relire l'état
